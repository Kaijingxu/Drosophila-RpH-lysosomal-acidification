# Drosophila-RpH-lysosomal-acidification

Data, R analysis scripts and FIJI workflows for quantitative imaging of Lamp1-positive endolysosomal acidification in Drosophila using the RpH ratiometric reporter.

\# Quantitative imaging of lysosomal acidification in Drosophila using RpH



This repository contains the minimally processed data tables, R analysis scripts, representative microscopy images and R session information supporting the manuscript:



\*\*Quantitative imaging of lysosomal acidification in Drosophila using a genetically encoded pH sensor\*\*



\## Overview



Lysosomal acidification is essential for lysosomal degradation, trafficking and cellular homeostasis. This study adapted the Lamp1-pHluorin-mCherry ratiometric reporter for GAL4/UAS-mediated expression in \*Drosophila\* and established tissue-specific quantitative workflows for the larval fat body and adult eye.



The reporter, termed RpH, provides a relative readout of acidification within Lamp1-positive endolysosomal compartments by normalising pH-sensitive pHluorin fluorescence to comparatively pH-stable mCherry fluorescence.



The endogenous `sgsh^s64w/s64w` mucopolysaccharidosis type IIIA model was used as a disease-relevant case study to evaluate genotype-dependent differences, assay reproducibility and pharmacological responses.
